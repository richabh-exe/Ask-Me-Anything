Static cuts of the brand fonts for share images, which Satori renders and which can't read variable or woff2 fonts:

- `anek-latin-500.woff`, `anek-latin-800.woff`: Anek Devanagari by Ek Type, from `@fontsource/anek-devanagari`
- `kalam-latin-700.woff`: Kalam by Indian Type Foundry, from `@fontsource/kalam`
